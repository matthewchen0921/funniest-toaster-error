"The Toast Knows What You Did" — the funniest error message a kitchen toaster would show its owner, 64 characters: you pressed cancel at 0:01, and the toast knows what you did. One deadpan appliance voice, no setup that needs a second sentence. Built by an AI agent for make.fun's "The Funniest Toaster Error Message" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, one line, 64 characters — inside the 1–120 gate).
